# Parity audit: v1 against v2

- Date: 2026-11-13
- v1: `camporee-conductor` at commit `4360d25`
- v2: this repo at commit `44f9cf5` (`main`)
- Parity definition (Jim, 2026-11-12): **all of v1 except #51; bracket mode (#105) is out.**

This replaces the stale gap table in the vault (`parity-gap.md`). I walked every v1 route in
`src/servers/collator.js`, `composer.js` and `landing.js`, every page in `public/`, every file in `scripts/` and the
`package.json` scripts. For each one I read the v2 code, not just issue titles.

Status values:

- **covered**: v2 does it, with the v2 files and the issue or PR.
- **covered differently**: v2 does it another way on purpose (ADR cited).
- **out**: not in scope: bracket mode (#105), #51, or dropped by an ADR. A few v1 housekeeping scripts are marked
  out on my own judgment, and say so.
- **missing**: not in v2.

v2 words are generic (Event, Group, Team, Activity, Competition, Judge, Official). v1 words are shown where the v1
route or page uses them.

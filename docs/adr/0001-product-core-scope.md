# ADR-0001 — Product core is station-based team competitions, plus planning artifacts
Date: 2026-10-25 · Status: Accepted
**Decision:** v2's core is designing and running station-rotation team competitions (judging, scoring, standings, awards) and sharing templates; plus adjacent planning features (Program Guide, rosters with contacts, light registration). It may grow toward a lighter event-management suite later.
**Why:** this core is what no off-the-shelf tool does; full event management (payments, lodging) competes with Eventbrite/CampDoc. Keep growth possible via modular design rather than building it now.

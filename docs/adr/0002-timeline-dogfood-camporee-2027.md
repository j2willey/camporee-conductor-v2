# ADR-0002 — Dogfood target: Coyote Creek Camporee, May 14–16, 2027

Date: 2026-10-25 · Status: Accepted
**Decision:** v2 must run the 2027 camporee. Design side operational by **end of January 2027**; Program Guide published **before April 1**; event May 14–16. Earlier is better (could offer to other districts). v1 stays deployable as fallback until v2 passes a dress rehearsal.

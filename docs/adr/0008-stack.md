# ADR-0008 — Stack

Date: 2026-10-25 · Status: Accepted (decided 2026-11-03, issue #4)
**Decision:** TypeScript monorepo; pure, heavily tested scoring/ranking package (no I/O); Node API (Hono or Fastify); SQLite + Drizzle; React + Vite for Composer, officials' views and judge PWA; judge sync as an append-only score-event log (no sync framework). New GitHub repo (portfolio).
**Why:** v1 had ranking logic duplicated in 4 places with no tests (and an announcer-sheet placement bug at Circus 2026); TS/React match job market; hand-rolled event log is small, testable, explainable.

## Amendment 2026-11-03 (issue #4): decided

- **API: Hono** (not Fastify), on Node via `@hono/node-server`. Web-standard Request/Response, tests call
  `app.request()` without a server, and Zod (already the schema source of truth) does request validation.
- **Composer web: React + Vite, React Router in library (SPA) mode** (not framework mode), TanStack Query,
  Tailwind.
- **DB access: Drizzle on better-sqlite3**, migrations generated by drizzle-kit and checked in.
- **The job-description check is non-blocking.** It informs what the portfolio emphasizes, not the
  framework choice, so this ADR is no longer provisional.

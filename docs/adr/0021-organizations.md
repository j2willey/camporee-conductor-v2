# ADR-0021 — Organizations own Events, Venue Profiles, Council/District Profiles and private Templates
Date: 2026-10-25 · Status: Accepted
Users are members of one or more Organizations with a role; per-Event collaborators still allowed (e.g., outside co-director). Event stays with the district when directors change.

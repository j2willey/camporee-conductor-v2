# ADR-0004 — Offline on-site deployment first; cloud soon after

Date: 2026-10-25 · Status: Accepted
**Decision:** first target is the off-grid on-site box (as Camp Chesebrough requires). After dogfooding in May 2027, add cloud hosting soon after. Architecture must not preclude cloud even though it ships later.

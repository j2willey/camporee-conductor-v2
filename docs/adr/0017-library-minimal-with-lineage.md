# ADR-0017 — Phase 1 template library is minimal, but lineage is modeled from day one

Date: 2026-10-25 · Status: Accepted
Phase 1: Circus 2026 imported as first Template; start an Event from a Template; save/fork individual Challenges. Community submission, review gate and AI Templatize are Phase 3.
Data model from day one: Challenge → parent Challenge, Event → parent Template, and external attribution (e.g., "theme from XYZ District, ABC Council 2025").
